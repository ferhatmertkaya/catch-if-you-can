# .gitattributes fuehrt seine LFS-Regeln einzeln je Datei statt als Muster, also faengt
# jedes neue Modell und jede neue Textur AUSSERHALB von LFS an und bleibt dort, wenn es
# niemand merkt. So sind diese hier hereingekommen.

# und dieses Projekt macht keinen Force-Push. Der Waechter faellt deshalb ueber die NAECHSTE

# kuerzer, ist etwas besser geworden, und das hat dann einen Diff.
#
# Was das kostet: GitHub warnt ueber 50 MiB und VERWEIGERT ueber 100 MiB. Die groesste hier
# ist 92 MiB. Ausserdem laedt jeder Klon diese Bytes mit, fuer immer.
